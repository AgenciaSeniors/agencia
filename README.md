# 🏢 Agencia Señores — Sitio Web Oficial

**Sitio web corporativo de la Agencia de Desarrollo de Software "Señores"**, optimizado para SEO local en Cuba, con blog de artículos técnicos y páginas de servicios geolocalizadas.

🌐 **Demo en vivo:** [agenciaseniors.github.io/agencia](https://agenciaseniors.github.io/agencia/)

---

## 📋 Descripción

Sitio web estático de una agencia de desarrollo de software ubicada en Sancti Spíritus, Cuba. Diseñado con enfoque en **posicionamiento SEO local**, cubriendo ciudades como Sancti Spíritus, Santa Clara y Cienfuegos. Incluye blog técnico con artículos sobre programación web, landing pages de servicios y optimización para motores de búsqueda.

---

## ✨ Características

- **SEO Local** — Páginas específicas por ciudad (`/programadores-sancti-spiritus`, `/diseno-web-santa-clara`, `/diseno-web-cienfuegos`)
- - **Blog técnico** — Artículos sobre desarrollo web y programación
  - - **Google Search Console** — Verificado con Google (`google94be4ac819c7115c.txt`)
    - - **Sitemap XML** — Mapa del sitio para indexación automática
      - - **Robots.txt** — Configuración para rastreadores web
        - - **404 personalizado** — Página de error amigable
          - - **Política de privacidad** — Página legal completa
            - - **Diseño responsive** — Compatible con dispositivos móviles y escritorio
              - - **GitHub Pages** — Desplegado con CI/CD automático (105+ deployments)

                ## 📁 Estructura del Proyecto

                ```
                agencia/
                ├── articulos/          ← Artículos del blog técnico
                ├── css/                ← Hojas de estilo
                ├── img/                ← Recursos visuales
                ├── js/                 ← Scripts JavaScript
                ├── index.html          ← Página principal
                ├── blog.html           ← Listado del blog
                ├── diseno-web-cienfuegos.html    ← SEO local Cienfuegos
                ├── diseno-web-santa-clara.html   ← SEO local Santa Clara
                ├── programadores-sancti-spiritus.html ← SEO local Sancti Spíritus
                ├── politica-privacidad.html      ← Política de privacidad
                ├── sitemap.xml         ← Mapa del sitio
                ├── robots.txt          ← Directivas para rastreadores
                └── 404.html            ← Página de error personalizada
                ```

                ## 🚀 Despliegue

                El sitio se despliega automáticamente en **GitHub Pages** con cada push a la rama `main`.

                URL de producción: [https://agenciaseniors.github.io/agencia/](https://agenciaseniors.github.io/agencia/)

                Para desarrollo local:
                ```bash
                git clone https://github.com/AgenciaSeniors/agencia.git
                cd agencia
                # Abrir index.html en el navegador o usar Live Server
                ```
